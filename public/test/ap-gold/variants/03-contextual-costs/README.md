# 03-contextual-costs — Decision-point

**Design stance:** Small quiet counter top-right + cost tags appended to relevant town markers.

**Key choices:**
- Layout: Dim understated top-right counter (rgba 0.6, #334466 border); portal gets '10 AP · 50gc' chip, store gets 'gold accepted'.
- Typography: 11px counter, 9-10px chips with black shadow.
- Interaction: Same keyboard/mouse; costs visible exactly at decision points.
- Battle: Same compact line as variant 01.

**Trade-offs:**
- Strong at: Resources appear where spending decisions happen; minimal visual noise.
- Weak at: Quiet counter may be overlooked; requires scanning markers for costs.

**Best-for:** Players who prefer contextual, decision-tied information over persistent HUDs.

**Mock data note:** AP 24/30, Gold 1,240gc, portal cost example '10 AP · 50gc' are placeholders. Real values from backend per docs/ap-economy.md.
