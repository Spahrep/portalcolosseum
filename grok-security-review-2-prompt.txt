## All Policies (verified)

Static data tables (attack, weapon_template, weapon_template_attack_mapping, monster_template, monster_template_attack_mapping, monster_instance):
- SELECT: auth.role() = 'authenticated' (RLS policy on public role)
- ALL (writes): auth.role() = 'service_role' (RLS policy on public role)
- Table-level GRANTs: anon has SELECT via table grant; authenticated has NO INSERT/UPDATE/DELETE table grants

invite_keys:
- Deny all (qual: false) on public role
- Only service_role can SELECT (new policy, roles: service_role)

User tables (player_inventory, weapon_instance, profiles):

- profiles also has "Public profiles are viewable by everyone" SELECT with qual: true
