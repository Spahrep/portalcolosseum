# Procedural Weapon Generation System (MVP)

**Source:** Jester's Ideas Log (2026-08-26)
**Status:** MVP Implementation
**Principle:** Randomness at all stages with normal distribution centered on base values.

## Overview

Weapons are procedurally generated using a template system that combines:

- **Base** values (core stat anchors)
- **Delta** ranges (per-weapon variation)
- **5 Attack Slots** (1 default + 4 configurable chance slots)

Each weapon instance is generated by rolling stats within the base/delta ranges of its template.

## Weapon Template Structure

### Core Fields
- **name**: e.g., "Wristblade", "Short Sword", "Greatsword"
- **weapon_type**: enum (sword, dagger, axe, staff, etc.)
- **base_damage**: int — average damage
- **damage_range**: int (+/-) — deviation from base at generation time
- **base_speed**: int — ticks per attack (lower = faster)
- **speed_variance**: int (+/-) — deviation from base speed
- **base_accuracy**: int — average accuracy%
- **accuracy_range**: int (+/-) — deviation from base accuracy

### Attack Slots
- **Slot 0**: Default "Attack" — always present, uses base stats unmodified (not stored in template)
- **Slot 1-4**: Each defined by two columns:
  - `slot_N_pool`: text[] — allowed attack names that can roll for this slot
  - `slot_N_chance`: double precision (0.0–1.0) — probability this slot is granted

Max attacks on a weapon = 1 (Slot 0) + up to 4 (Slots 1-4) = 5.

### Stat Generation Formula
```
Final Damage   = Base_Damage ± rand_normal(0..Damage_Range, mean=Base_Damage)
Final Speed    = Base_Speed ± rand_normal(0..Speed_Variance, mean=Base_Speed)   // lower is faster
Final Accuracy = Base_Accuracy ± rand_normal(0..Accuracy_Range, mean=Base_Accuracy)
```

Attack slots are resolved per-slot:
```
for slot in 1..4:
    if random() < slot_N_chance:
        grant 1 random attack from slot_N_pool
```

### Example Weapon Stats
```
base_damage: 35
damage_range: 6        → rolled damage 29-41
base_speed: 27
speed_variance: 3      → rolled speed 24-30 (24 = fastest)
base_accuracy: 85
accuracy_range: 5      → rolled accuracy 80-90%

slot_1_pool: ["Quick Slash", "Feint"]
slot_1_chance: 1.0
slot_2_pool: ["Cleave", "Heavy Chop"]
slot_2_chance: 0.8
slot_3_pool: ["Whirlwind"]
slot_3_chance: 0.4
slot_4_pool: ["Power Attack", "Battle Cry", "Shield Bash"]
slot_4_chance: 0.1
```

### Speed Convention
- **Lower speed value = faster attacks**
- `speed` represents "ticks per attack" — a weapon with speed 25 attacks roughly every 0.25 game seconds
- Example: speed of 55 ≈ 1.8 attacks/sec; speed of 25 ≈ 4 attacks/sec
- DPS = Damage × (100 / Speed)

## Classification (A/B/C Grades)
**The grade is computed *after* all stats are rolled**, not as an input to generation. Each stat range is rolled independently using the Base + Delta formula. The resulting grade is a **UI/UX label** that tells the player "how good" their weapon is without making them do the math.
