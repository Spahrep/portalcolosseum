# Procedural Weapon Generation System (MVP)

**Source:** Jester's Ideas Log (2026-08-26)
**Status:** MVP Implementation
**Updated:** 2026-09-05 — Slot 0 now stored as FK column, attack selection via mapping table with weights
**Principle:** Randomness at all stages with normal distribution centered on base values.

## Overview

Weapons are procedurally generated using a template system that combines:

- **Base** values (core stat anchors)
- **Delta** ranges (per-weapon variation)
- **5 Attack Slots** (1 default + 4 configurable chance slots)

Each weapon instance is generated by rolling stats within the base/delta ranges of its template. Once generated, the weapon is stored in the `weapon_instance` table with its rolled stats and selected attacks.

## Weapon Template Structure

### Core Fields
- **name**: e.g., "Wristblade", "Short Sword", "Greatsword"
- **weapon_type**: enum (sword, dagger, axe, staff, etc.)
- **base_damage**: int — average damage
- **damage_range**: int (+/-) — deviation from base at generation time
- **base_speed**: int — ticks per attack (lower = faster)
- **speed_variance**: int (+/-) — deviation from base speed
- **base_accuracy**: int — average accuracy%
- **accuracy_range**: int (+/-) — deviation from base accuracy

### Attack Slots
- **Slot 0**: Default "Attack" — always present, uses base stats unmodified. Stored as `slot_0_attack_id` (NOT NULL FK → `attack.id`) on both `weapon_template` (defines the default for the template) and `weapon_instance` (stores the resolved attack on each generated weapon). Currently all templates use attack.id=1 ("Attack").
- **Slots 1–4**: Pool membership resolved via the `weapon_template_attack_mapping` junction table (links `weapon_template` → `attack` → `slot` via FK integer IDs). Each template has its eligible attacks defined as rows in that table.
- **Slot probabilities**: The `weapon_template` table retains `slot_N_chance` columns (0.0–1.0) for each slot. These encode how likely a given slot is to *activate* during generation — the mapping table says *which* attacks are eligible, the chance columns say *whether* the slot fires.
- **Weighted selection**: The `weapon_template_attack_mapping` table has a `weight` column (real, default 1.0) used for weighted random selection within each slot.

Max attacks on a weapon = 1 (Slot 0) + up to 4 (Slots 1–4) = 5.

### Stat Generation Formula
```
Final Damage   = Base_Damage ± rand_normal(0..Damage_Range, mean=Base_Damage)
Final Speed    = Base_Speed ± rand_normal(0..Speed_Variance, mean=Base_Speed)   // lower is faster
Final Accuracy = Base_Accuracy ± rand_normal(0..Accuracy_Range, mean=Base_Accuracy)
```

Attack slots are resolved with **conditional probability** — Slot N is only rolled if Slot N-1 succeeded (Slot 1 has no prerequisite since Slot 0 "Attack" is always present). Pool membership comes from the `weapon_template_attack_mapping` junction table:
```javascript
// Slot 0: Always granted "Attack", stored as slot_0_attack_id on both weapon_template and weapon_instance
// Slots 1-4: Conditional probability, eligible attacks from mapping table with weighted selection
previous_slot_succeeded = true  // Slot 0 always succeeds
for slot in 1..4:
    if previous_slot_succeeded AND random() < slot_N_chance:
        eligible_attacks = SELECT attack_id, weight
                           FROM weapon_template_attack_mapping wta
                           WHERE wta.weapon_template_id = template.id
                           AND wta.slot = slot
        grant 1 random attack from eligible_attacks weighted by wta.weight
        previous_slot_succeeded = true
    else:
        previous_slot_succeeded = false
        break  // No more slots will activate
```


### Example Weapon Stats
```
weapon_template: Wristblade (dagger)
base_damage: 25
damage_range: 5        → rolled damage 20-30
base_speed: 18
speed_variance: 2      → rolled speed 16-20
base_accuracy: 88
accuracy_range: 4      → rolled accuracy 84-92%

Eligible attacks (from weapon_template_attack_mapping):
  Slot 0: Attack (always, via slot_0_attack_id FK)
  Slot 1: Attack         chance = 1.0
  Slot 2: Quick Slash, Precision Strike   chance = 0.8
  Slot 3: Power Attack   chance = 0.15
  Slot 4: (none — slot_4_chance = 0)
```

### Speed Convention
- **Lower speed value = faster attacks**
- `speed` represents "ticks per attack" — a weapon with speed 25 attacks roughly every 0.25 game seconds
- Example: speed of 55 ≈ 1.8 attacks/sec; speed of 25 ≈ 4 attacks/sec
- DPS = Damage × (100 / Speed)

## Classification (A/B/C Grades)
**The grade is computed *after* all stats are rolled**, not as an input to generation. Each stat range is rolled independently using the Base + Delta formula. The resulting grade is a **UI/UX label** that tells the player "how good" their weapon is without making them do the math.
