### ① — Attack timing model: docs/decided-rule say `speed + flat ticks`; code is now `speed × multiplier` (PC-107..110b)

**The decided rule and docs describe `speed + rolled flat prepare/cooldown ticks`. The
shipped engine now computes timing as a pure multiplier on speed and has DROPPED the flat
timing columns.**

| | Side A (decided rule — PC-DEC-034/055, Spahrep) | Side B (code — PC-107..110b, slademini 2026-09-30) |
|---|---|---|
| Player windup | `weaponSpeed + rollStat(prepare_time, prepare_time_range)` (PC-DEC-034 note; battle-status-ui.md) | `weaponSpeed * rollMultiplier(prepare_time_multiplier, prepare_time_multiplier_range)` (api/combat/[...path].js:891) |
| Monster windup | `mon.speed + rollStat(prepare_time, prepare_time_range)` (PC-DEC-055 note; battle-status-ui.md:234) | `max(1, floor(mon.speed * rollMultiplier(prepare_time_multiplier, ...)))` (engine.js:181, PC-110b) |
| Cooldown | `weapon/mon.speed + rollStat(cooldown_time, cooldown_time_range)` (same docs) | `weapon/mon.speed * rollMultiplier(cooldown_time_multiplier, ...)`, floored `max(1, floor(...))` |
